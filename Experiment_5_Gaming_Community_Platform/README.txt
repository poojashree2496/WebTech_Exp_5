EXPERIMENT 5 - GAMING COMMUNITY PLATFORM
JavaScript DOM Elements & Events

Files:
1. index.html - complete interactive gaming community platform
2. Apple.jpg - fruit reward image
3. Orange.jpg - fruit reward image
4. heads.jpg - coin flip image
5. tails.jpg - coin flip image

RUN:
- Open index.html directly in a browser, or
- In VS Code, install Live Server and choose "Open with Live Server", or
- Run: python -m http.server 5500
  Then open: http://localhost:5500

DEPLOY:
1. Create a GitHub repository.
2. Upload all files while preserving the same folder structure.
3. Enable GitHub Pages from Settings > Pages.
4. Select the main branch and root folder.
5. Save and open the generated Pages URL.

The currency conversion factors and cake pricing/tax/tip rules follow the provided laboratory reference material.
